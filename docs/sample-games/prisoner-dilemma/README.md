# Iterated Prisoner's Dilemma（重复囚徒困境）

2-player, 15-round game. Generated by Codex from the Leverage `/ai` context document.

## Rules

Each round, both players simultaneously choose `C` (cooperate) or `D` (defect).

| P1 | P2 | P1 Score | P2 Score |
|----|----|----------|----------|
| C  | C  | +3       | +3       |
| C  | D  | +0       | +5       |
| D  | C  | +5       | +0       |
| D  | D  | +1       | +1       |

After 15 rounds, highest cumulative score wins. Draws if equal.

## Strategy Notes

- **Always Defect** exploits cooperators, but mutual defection (1+1) loses to mutual cooperation (3+3)
- **Tit for Tat** is the classic baseline — nice, retaliatory, forgiving
- Optimal strategies depend heavily on opponent model; this game is great for testing ML bots
